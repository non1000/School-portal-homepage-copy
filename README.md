# Afe Babalola University Homepage Clone

A front-end recreation of the Afe Babalola University homepage, built during my internship at [Digital Dreams ICT Academy] as a practice project.

**[Live demo]()**

![Screenshot of the homepage](screenshots/home.png)

## About

I built this to practise turning a real, multi-section website into clean HTML and CSS. It covers the main sections of the original homepage, including [navigation bar, sign-in section, footer].

## Built with

- HTML5
- CSS3
